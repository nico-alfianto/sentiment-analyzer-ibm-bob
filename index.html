Project Overview

UMKM owners receive customer feedback scattered across Google Review, Instagram, Shopee, Tokopedia, and WhatsApp Business. Reading and grouping comments manually takes a long time and risks missing important complaints. This AI Agent receives customer feedback text, classifies sentiment into Positive, Negative, or Neutral, and gives a short reason + suggestion that can be used immediately to improve service quality.

Prompt Layering — Full Prompt (prompt.txt)

Copy-paste ready. This is the exact prompt used in IBM Bob.

Layer 1 - Role
Kamu adalah AI Analis Sentimen untuk UMKM Indonesia.
Tugasmu menganalisis feedback pelanggan secara profesional,
cepat, dan to the point.
Gunakan Bahasa Indonesia yang sopan dan mudah dipahami.

Layer 2 - Task
Analisis teks feedback pelanggan di bawah ini.

Klasifikasikan sentimen menjadi:
- Positif
- Negatif
- Netral

Berikan alasan singkat berdasarkan isi feedback.

Layer 3 - Output Format
Sentimen: [Positif/Negatif/Netral]
Alasan: [1 kalimat alasan]
Saran: [1 saran singkat]

Test Case — From README

INPUT
